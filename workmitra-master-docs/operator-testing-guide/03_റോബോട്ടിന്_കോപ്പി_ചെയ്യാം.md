# റോബോട്ടിന് കോപ്പി ചെയ്യാം (Cursor AI)

കോഡ് അറിയേണ്ടതില്ല. **ഇവിടെ നിന്ന് copy → Cursor chat-ൽ paste** മാത്രം.

---

## ① എല്ലാം ശരിയാണോ എന്ന് ചോദിക്കാൻ (എഡിറ്റിങ്ങിന് മുമ്പ്)

```
Job Mitra ടെസ്റ്റ് ചെക്ക് ചെയ്യൂ.

ഇത് റൺ ചെയ്യൂ:
npm run test:e2e:headless

എനിക്ക് മലയാളത്തിൽ ലളിതമായി പറയൂ:
- എത്ര passed, എത്ര failed
- 15 passed ആണോ ഇല്ലയോ
- failed ഉണ്ടെങ്കിൽ എന്ത് ചെയ്യണം (എനിക്ക് കോഡ് വേണ്ട)

ഫയൽ എഡിറ്റ് ചെയ്യരുത് — ആദ്യം റിപ്പോർട്ട് മാത്രം.
```

---

## ② ടെസ്റ്റ് ഫെയിൽ ആയാൽ (ടെർമിനൽ ലോഗ് ഒപ്പം)

മുമ്പ് ടെസ്റ്റ് റൺ ചെയ്ത് **മുഴുവൻ കറുത്ത വിൻഡോയുടെ ടെക്സ്റ്റും** copy ചെയ്യുക.

```
Job Mitra ടെസ്റ്റ് ഫെയിൽ ആയി. നോക്കൂ.

ഞാൻ റൺ ചെയ്തത്:
npm run test:e2e:headless

ടെർമിനൽ ഔട്ട്പുട്ട്:
[ഇവിടെ paste ചെയ്യുക — മുഴുവൻ ടെക്സ്റ്റ്]

എനിക്ക് മലയാളത്തിൽ:
1. എന്താണ് പ്രശ്നം (ഒരു വാക്യം)
2. എനിക്ക് എന്ത് ചെയ്യണം
3. നീ ഫിക്സ് ചെയ്യണമെങ്കിൽ ആദ്യം എനോട് ചോദിക്കൂ

എഡിറ്റ് ചെയ്യുന്നതിന് മുമ്പ് എന്റെ "ഓക്കേ" കാത്തിരിക്കൂ.
```

---

## ③ Shift + Career മാത്രം വേഗം ചെക്ക്

```
ഇത് റൺ ചെയ്ത് ഫലം പറയൂ:
npm run test:e2e:headless -- tests/e2e/shift-full-circuit.spec.ts tests/e2e/career-full-circuit.spec.ts

2 passed ആണോ? മലയാളത്തിൽ ചെറിയ റിപ്പോർട്ട്.
```

---

## ④ ഫിക്സ് ചെയ്തതിന് ശേഷം — വീണ്ടും ചെക്ക്

```
നീ ചെയ്ത ഫിക്സ് ശരിയാണോ എന്ന് വീണ്ടും റൺ ചെയ്യൂ:
npm run test:e2e:headless

15 passed വന്നാൽ മലയാളത്തിൽ "എല്ലാം ശരി" എന്ന് പറയൂ.
```

---

## ⑤ എഡിറ്റിങ്ങ് തുടങ്ങാൻ അനുവാദം

```
ടെസ്റ്റ് 15/15 passed ആയി. ഇനി എഡിറ്റിങ്ങ് തുടങ്ങാം.

എഡിറ്റ് ചെയ്യേണ്ടത്: [ഇവിടെ നിങ്ങൾക്ക് വേണ്ടത് എഴുതുക — ഉദാ: "എംപ്ലോയി ഹോം പേജ് ബട്ടൺ നിറം"]

എഡിറ്റ് കഴിഞ്ഞ് shift/career ടെസ്റ്റ് വീണ്ടും റൺ ചെയ്യണം.
```

## ഓർക്കുക

| ചെയ്യുക                                     | ചെയ്യരുത്                                     |
| ------------------------------------------- | --------------------------------------------- |
| `START-HERE.cmd` അല്ലെങ്കിൽ headless കമാൻഡ് | `npm run test:e2e` (UI) — പുതിയവർക്ക് കുഴപ്പം |
| failed ആയാൽ മുഴു ലോഗ് paste                 | ഒരേ വരി മാത്രം paste                          |
| റോബോട്ടിന് "ഓക്കേ" പറഞ്ഞ് ശേഷം എഡിറ്റ്      | അനുവാദമില്ലാതെ കോഡ് മാറ്റം                    |
