## ⚠️ കുഴപ്പമില്ലാത്ത “എറർ” (ഇഗ്നോർ ചെയ്യാം)

ഇവ കണ്ടാൽ **ടെസ്റ്റ് പാസ് ആണെങ്കിൽ** വിഷമിക്കേണ്ട:

| കാണുന്നത്                              | അർത്ഥം                                         |
| -------------------------------------- | ---------------------------------------------- |
| `npm warn Unknown env config "devdir"` | Warning മാത്രം — കുഴപ്പമില്ല                   |
| `ENOENT ... traces ... stacks`         | UI മോഡിൽ trace ഫയൽ — headless-ൽ സാധാരണയില്ല    |
| `Test ended` + `Operations Executive`  | പലപ്പോഴും മുകളിലെ trace പ്രശ്നത്തിന്റെ പിന്മുറ |
| `NO_COLOR env is ignored`              | നിറം സംബന്ധിച്ച warning — കുഴപ്പമില്ല          |

**നിങ്ങൾ `START-HERE.cmd` → Enter (headless) ഉപയോഗിച്ചാൽ** മുകളിലെ trace എറർ വരാതിരിക്കാൻ ശ്രമിക്കും.
