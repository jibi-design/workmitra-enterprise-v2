# ടെസ്റ്റ് എങ്ങനെ റൺ ചെയ്യാം

## രീതി A — ഡബിൾ ക്ലിക്ക് + Enter (ഏറ്റവും എളുപ്പം) ⭐

1. ഈ ഫോൾഡർ തുറക്കുക:  
   `workmitra-master-docs\operator-testing-guide`
2. **`START-HERE.cmd`** ഡബിൾ ക്ലിക്ക്
3. മെനു വരും — **ഒന്നും ടൈപ്പ് ചെയ്യാതെ Enter** അമർത്തുക
4. ~1 മിനിറ്റ് കാത്തിരിക്കുക
5. **`15 passed`** കണ്ടാൽ ശരി

> വേഗം ചെക്ക് വേണമെങ്കിൽ മെനുവിൽ **2** ടൈപ്പ് ചെയ്യുക (Shift+Career മാത്രം).

വിശദ പട്ടിക: **`05_റൺ_ഫയലുകളുടെ_പട്ടിക.md`**

## രീതി B — PowerShell നേരിട്ട് (ഓപ്ഷൻ)

1. **Windows Key** അമർത്തി `PowerShell` ടൈപ്പ് ചെയ്ത് തുറക്കുക
2. ഈ കമാൻഡ് copy ചെയ്ത് paste ചെയ്ത് Enter:

```powershell
cd C:\projects\WorkMitra_Enterprise_v2
npm run test:e2e:headless
```

3. കാത്തിരിക്കുക (~1 മിനിറ്റ്)
