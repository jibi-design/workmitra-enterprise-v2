# പതിവ് ചോദ്യങ്ങൾ

---

### Q1. ഞാൻ ഡെവലപ്പർ അല്ല — ഇത് ചെയ്യാൻ കഴിയുമോ?

**അതെ.** `RUN-ALL-TESTS.cmd` ഡബിൾ ക്ലിക്ക് മാത്രം. കോഡ് വായിക്കേണ്ട.

---

### Q2. `15 passed` എന്താണ്?

App-ന്റെ **15 ഓട്ടോമാറ്റിക് പരിശോധനകൾ** എല്ലാം വിജയിച്ചു എന്നർത്ഥം.  
PC-യിൽ RAM test pass ആയതുപോലെ.

---

### Q3. `START-HERE.cmd` vs `npm run test:e2e` — വ്യത്യാസം?

|            | START-HERE.cmd        | npm run test:e2e |
| ---------- | --------------------- | ---------------- |
| എങ്ങനെ     | ഡബിൾ ക്ലിക്ക് + Enter | Cursor / ടെർമിനൽ |
| UI         | മെനു + കറുത്ത വിൻഡോ   | Playwright വിൻഡോ |
| നിങ്ങൾക്ക് | ⭐ ഇത് മാത്രം         | വേണ്ട            |

---

### Q4. ടെസ്റ്റ് റൺ ചെയ്യുമ്പോൾ App ബ്രൗസർ തുറക്കണോ?

**ഇല്ല.** പിന്നിൽ സ്വയം റൺ ചെയ്യും. ചിലപ്പോൾ ചെറിയ വിൻഡോ മിന്നും — അത് സാധാരണമാണ്.

---

### Q5. ഇന്റർനെറ്റ് വേണോ?

ആദ്യ റൺ / npm ഇൻസ്റ്റാൾ ചെയ്തിട്ടില്ലെങ്കിൽ വേണം.  
പിന്നീട് പലപ്പോഴും ലോക്കലായി റൺ ചെയ്യും.

---

### Q6. റെഡ് എറർ കണ്ടാൽ App ഉപയോഗിക്കാൻ പറ്റുമോ?

Play Store / ഡെമോ ഉപയോഗിക്കാം.  
എറർ = **ഓട്ടോമാറ്റിക് ടെസ്റ്റ്** ഒരു സാഹചര്യം പാസ് ആയില്ല — ഡെവലപ്പർ/റോബോട്ട് നോക്കണം.

---

### Q7. എത്ര തവണ റൺ ചെയ്യണം?
