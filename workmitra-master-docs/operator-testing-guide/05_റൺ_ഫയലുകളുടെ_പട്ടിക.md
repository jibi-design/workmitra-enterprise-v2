## ഇവ റൺ ചെയ്യുന്നില്ല — എന്തുകൊണ്ട്?

ഡെവലപ്പർമാർ മാത്രം ഉപയോഗിക്കുന്ന കമാൻഡുകൾ. നിങ്ങൾക്ക് **വേണ്ട**.

| കമാൻഡ്              | എന്താണ്             | നിങ്ങൾക്ക് വേണ്ടാത്തത്   |
| ------------------- | ------------------- | ------------------------ |
| `npm run build`     | App ബിൽഡ്           | എറർ വായിക്കാൻ കഷ്ടം      |
| `npm run lint`      | കോഡ് സ്റ്റൈൽ        | ടെസ്റ്റ് അല്ല            |
| `npm run preflight` | build+lint+security | 5–10 മിനിറ്റ്, ഡെവ് ജോബ് |
| `npm run test:e2e`  | Playwright UI       | trace എറർ വരാം           |
| `npm run dev`       | App തുറക്കാൻ        | ടെസ്റ്റ് ചെക്ക് അല്ല     |

**നിങ്ങളുടെ ജോലി = `15 passed` ഉണ്ടോ എന്ന് നോക്കുക.** ബാക്കി റോബോട്ട്/ഡെവലപ്പർ.
