# ഫോൺ ↔ വീട്ടിലെ PC — ആദ്യം സെറ്റപ്പ് (സ്റ്റെപ്പ് ബൈ സ്റ്റെപ്പ്)

> **ആർക്ക്:** ഹാർഡ്വെയർ ടെക്നീഷ്യൻ — കോഡ് അറിയേണ്ട.  
> **ഉദ്ദേശ്യം:** ഓഫീസിൽ നിന്ന് വീട്ടിലെ PC → Google AI Studio + Cursor ഉപയോഗിക്കാൻ.

---

## മുഴുവൻ ചിത്രം (3 വാക്കിൽ)

1. **Tailscale** — ഫോണും PC-യും സുരക്ഷിതം കണക്ട് (വീട്ടിലെ വൈഫൈ വേണ്ടി വരും)
2. **RustDesk** — PC സ്ക്രീൻ ഫോണിൽ കാണാൻ
3. **Copy ബ്ലോക്ക്** — Cursor ഉത്തരം AI Studio-യിലേക്ക്

---

# ഭാഗം A — വീട്ടിൽ (PC-യിൽ) — ഒരിക്കൽ മാത്രം

## A1. PC തയ്യാർ

1. PC **ഓണ്** ചെയ്ത് **ഇന്റർനെറ്റ്** (വൈഫൈ) കണക്ട് ചെയ്തിരിക്കുക
2. **Windows Update** pending ഇല്ലെങ്കിൽ നല്ലത് (ഇപ്പോൾ നിർബന്ധമില്ല)

## A2. Tailscale ഇൻസ്റ്റാൾ (PC)

1. ബ്രൗസർ തുറക്കുക
2. പോകുക: **https://tailscale.com/download**
3. **Windows** → Download → ഫയൽ റൺ ചെയ്യുക
4. ഇൻസ്റ്റാൾ ചെയ്ത് **Sign in**
5. **Google അക്കൗണ്ട്** (നിങ്ങൾ ഉപയോഗിക്കുന്നത്) കൊണ്ട് ലോഗിൻ
6. “Connect” / “Join network” അനുവദിക്കുക
7. PC **Tailscale ON** ആണെന്ന് സിസ്റം ട്രേയിൽ ഐക്കൺ കാണാം

**എഴുതി വെക്കുക:** PC-യുടെ Tailscale പേര് (ഉദാ: `home-pc`)

## A3. RustDesk ഇൻസ്റ്റാൾ (PC)

1. പോകുക: **https://rustdesk.com**
2. **Download** → Windows → ഇൻസ്റ്റാൾ
3. RustDesk തുറക്കുക
4. ഇടത് വശം **Your Desktop ID** — **8 അക്കം** (ഉദാ: `123 456 789`)
5. **Password** സെറ്റ് ചെയ്യുക (ഓർമ്മിക്കാൻ എളുപ്പം, മറ്റാർക്ക് പറയരുത്)

**എഴുതി വെക്കുക:**

| വിവരം       | എഴുതുക                                  |
| ----------- | --------------------------------------- |
| RustDesk ID | __________                              |
| Password    | __________ (വീട്ടിൽ മാത്രം സൂക്ഷിക്കുക) |

5. RustDesk → **Settings** → **Security** → **Permanent password** ON (ഉണ്ടെങ്കിൽ)

## A4. Sleep മോഡ് (Shutdown അല്ല)

1. **Settings** → **System** → **Power**
2. **Sleep:** പ്ലഗ് ഇൻ ചെയ്തിരിക്കുമ്പോൾ **30 മിനിറ്റ്** അല്ലെങ്കിൽ **Never** (ആദ്യം ടെസ്റ്റ് ചെയ്യുമ്പോൾ Never നല്ലത്)
3. **Shutdown ചെയ്യരുത്** — വീട് വിടുമ്പോൾ **Sleep** മതി (ആദ്യം ടെസ്റ്റ് കഴിഞ്ഞ്)

**Sleep ചെയ്യാൻ:** Start → Power → **Sleep**

## A5. ജോലി ആപ്പുകൾ (PC)

1. **Chrome** തുറക്കുക → **https://aistudio.google.com** → ബുക്ക്മാർക്ക്
2. **Cursor** തുറക്കുക → Job Mitra പ്രോജക്റ്റ്
3. ഡെസ്ക്ടോപ്പിൽ ഷോർട്ട്കട്ട്:  
   `workmitra-master-docs\operator-testing-guide\START-HERE.cmd`

## A6. വീട്ടിൽ ആദ്യ ടെസ്റ്റ് (ഫോൺ ഇതേ വൈഫൈയിൽ)

ഇത് ചെയ്താൽ ഓഫീസിൽ പോകുന്നതിന് മുമ്പ് ഉറപ്പാകും.

# ഭാഗം B — ഫോണിൽ — ഒരിക്കൽ മാത്രം

## B1. Tailscale (ഫോൺ)

1. **Play Store** (Android) അല്ലെങ്കിൽ **App Store** (iPhone)
2. **Tailscale** സെർച്ച് → Install
3. തുറക്കുക → **അതേ Google അക്കൗണ്ട്** കൊണ്ട് Sign in
4. **Connect** ON

## B2. RustDesk (ഫോൺ)

1. Store-ൽ **RustDesk** Install
2. തുറക്കുക
3. **ID** ടൈപ്പ് ചെയ്യുക (PC-യിൽ എഴുതിയ 8 അക്കം)
4. **Connect** → Password നൽകുക
5. PC സ്ക്രീൻ ഫോണിൽ കാണണം ✅

## B3. വീട്ടിൽ ടെസ്റ്റ് (മൊബൈൽ ഡാറ്റ)

1. ഫോണിന്റെ **വൈഫൈ ഓഫ്** → **മൊബൈൽ ഡാറ്റ** ON
2. Tailscale ON
3. RustDesk → PC ID → Connect
4. കണക്ട് ആയാൽ — **ഓഫീസിൽ നിന്നും വർക്ക് ചെയ്യാം** ✅

# ഭാഗം C — ഓഫീസിൽ ജോലി (എല്ലാ ദിവസവും)

## C1. PC ഉണർത്തൽ

| സ്ഥിതി                 | ചെയ്യുക                                                   |
| ---------------------- | --------------------------------------------------------- |
| PC **ഓണ്** / **Sleep** | ഫോണിൽ RustDesk → Connect (Sleep-ൽ നിന്ന് ഉണരാം)           |
| PC **Shutdown**        | വീട്ടിൽ ആരെങ്കിലും ഓണ് ചെയ്യണം — അതുകൊണ്ട് Shutdown വേണ്ട |

## C2. ജോലി ക്രമം

1. ഫോണിൽ **Tailscale** ON
2. **RustDesk** → Connect → വീട്ടിലെ സ്ക്രീൻ കാണും
3. PC സ്ക്രീനിൽ **Google AI Studio** — പ്രോംപ്റ്റ് / നിർണയം
4. AI Studio-യിൽ **Copy** ബട്ടൺ → Cursor-ൽ **Paste**
5. Cursor ജോലി ചെയ്യും
6. ഉത്തരം താഴേ **AI STUDIO COPY** → **Copy** ബട്ടൺ
7. AI Studio-ൽ **Paste** → ഫൈനൽ ഡിസിഷൻ
8. ടെസ്റ്റ് വേണമെങ്കിൽ: `START-HERE.cmd` ഡബിൾ ക്ലിക്ക് → Enter → `15 passed` നോക്കുക

## C3. ജോലി കഴിഞ്ഞ്

1. PC **Sleep** (Start → Power → Sleep) — റിമോട്ട് വഴിയും ചെയ്യാം
2. RustDesk Disconnect
3. Tailscale ON വെച്ചാലും കുഴപ്പമില്ല (ബാറ്ററി കുറയാം)
